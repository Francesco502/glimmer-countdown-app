# Bundled font modifications

The fonts in `app/src/main/res/font/` are Modified Versions (SIL OFL 1.1, section 1)
of the upstream fonts below. They are generated by `scripts/fonts/subset-fonts.py`;
input and output SHA-256 sums are recorded in `scripts/fonts/fonts.sha256`.

| Bundled file | Family name | Upstream font | License |
| --- | --- | --- | --- |
| `glimmer_serif.ttf` (variable, wght 200-900) | Glimmer Serif | Noto Serif SC 2.003 (variable, Adobe/Google) | [OFL-NotoSerifSC.txt](OFL-NotoSerifSC.txt) |
| `glimmer_xiaowei_regular.ttf` | Glimmer Xiaowei | ZCOOL XiaoWei 1.000 | [OFL-ZCOOLXiaoWei.txt](OFL-ZCOOLXiaoWei.txt) |

## Modifications

- Glimmer Serif: glyph coverage reduced to `scripts/fonts/glimmer-charset.txt`
  (all GB2312, ASCII/Latin-1, CJK and fullwidth punctuation, lunar calendar characters,
  and every character used by the app's string resources and Kotlin sources). The
  variable `wght` axis is kept; the app pins 300 / 400 / 500 / 600 via `FontVariation`.
- Glimmer Xiaowei (display only): reduced to `scripts/fonts/glimmer-xiaowei-charset.txt`
  (GB2312 level-1 hanzi only, plus the same non-hanzi, string-resource and lunar sets).
  Missing characters fall back to the system font.
- Hinting instructions, vertical metrics (`vhea`/`vmtx`) and `DSIG` removed; glyph names dropped.
- Font names (name IDs 1, 2, 3, 4, 6, 16, 17, and named-instance PostScript names) changed
  to "Glimmer Serif" / "Glimmer Xiaowei".
  Neither upstream license declares a Reserved Font Name; the fonts are renamed anyway so the
  modified versions are not presented under the original names. Copyright (ID 0), trademark
  (ID 7), manufacturer, and license (IDs 13/14) records are kept unchanged.

The modified fonts remain under the SIL Open Font License 1.1, and the license texts in this
directory apply to them unchanged. The unmodified originals are available from the upstream
projects and from this repository's git history (commit `f57d729` and earlier).
