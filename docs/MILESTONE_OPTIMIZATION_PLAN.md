# 重大时间节点功能及 UI 优化方案

本文档针对「显示距离重大时间节点的天数」及其**节点提醒**功能，给出可执行的优化方案。

---

## 一、当前实现概况

- **显示逻辑**：在详情/首页卡片中，对纪念日/周年类事件显示「距离 XX 天 还有 N 天」
- **节点配置**：默认 100～1000 天（100 递增），支持自定义添加/删除，恢复默认
- **提醒机制**：目前仅有**事件目标日期**提醒（remindEnabled、remindDaysBefore），**无节点专属提醒**

---

## 二、核心需求：节点提醒可配置

用户希望：
- **是否提醒**：由用户决定是否在临近重大节点时收到通知
- **提醒提前量**：提前多少天提醒，由用户自行设定（如 7 天、3 天、1 天）

### 方案 A：全局节点提醒（推荐）

在「设置 → 显示」中增加：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 节点临近提醒 | 开关，是否在临近重大节点时提醒 | 关 |
| 提前天数 | 下拉/输入：1 / 3 / 7 / 14 天 | 7 天 |

- **存储**：`UserPreferencesRepository` 新增 `milestoneRemindEnabled`、`milestoneRemindDaysAhead`
- **调度**：`ReminderScheduler` 或新建 `MilestoneReminderScheduler`，在事件达到「下一节点 - 提前天数」时触发
- **实现复杂度**：中
- **优点**：一次配置，所有纪念日类事件共享；逻辑清晰
- **缺点**：无法按节点或事件细粒度控制

### 方案 B：按节点配置提醒

每个节点可单独设置：
- 100 天：提前 7 天提醒 ✓
- 200 天：不提醒 ✗
- 365 天：提前 3 天提醒 ✓
- …

- **存储**：`Map<Long, MilestoneReminderConfig>` 或 JSON 结构
- **UI**：在「自定义重大节点」每个标签旁增加提醒开关 + 提前天数
- **实现复杂度**：高
- **优点**：灵活，用户可精准控制
- **缺点**：配置项多，UI 易拥挤

### 方案 C：按事件 + 全局默认

- 事件可覆盖：在事件编辑页增加「节点提醒」开关，覆盖全局
- 未覆盖时使用全局默认
- **实现复杂度**：高
- **优点**：兼顾灵活与简洁
- **缺点**：逻辑和 UI 都更复杂

**建议**：优先实现**方案 A**，若用户反馈需要更细粒度，再迭代到 B/C。

---

## 三、节点提醒技术实现要点

### 3.1 调度逻辑

1. **触发时机**：对每个「周年 / 每年重复」事件，计算下一节点及对应提醒时间
   - 若 `currentDays <= nextMilestone` 且 `currentDays >= nextMilestone - remindDaysAhead`，则调度提醒
2. **WorkManager**：可复用 `ReminderWorker`，或新建 `MilestoneReminderWorker`，用 `eventId + milestoneValue` 作为 tag，避免重复
3. **周期检查**：因节点会随日期变化，建议：
   - 事件增删改时重算并重新调度
   - 或使用 `PeriodicWork` 每天校验一次

### 3.2 通知内容

- 标题：`倒计时提醒：{事件标题}`
- 正文：`距离 {节点描述} 还有 {N} 天`
- 与现有「目标日期提醒」区分：可在通知 channel 中增加子类型或不同 title 前缀

### 3.3 数据模型扩展

```
UserPreferencesRepository 新增：
- milestoneRemindEnabled: Boolean (default: false)
- milestoneRemindDaysAhead: Int (default: 7)
```

## 四、UI 优化方案

### 4.1 设置页 - 节点相关

1. **文案** ✓ 已改为「显示距离重大时间节点的天数」
2. **恢复默认**：当前恢复为 `100, 200, …, 1000`，可补充说明「默认 100～1000 天，后续建议以 500 递增」
3. **添加节点**：
   - 占位符可改为「添加天数，如 200 或 1500」，提示 1000 后以 500 递增
   - 可选：增加「快捷添加 1500 / 2000」按钮，减少手动输入
4. **节点提醒配置**（方案 A）：
   - 在「显示重大节点」开关下方或「自定义重大节点」区块内，增加：
     - 开关：节点临近提醒
     - 下拉：提前 1 / 3 / 7 / 14 天

### 4.2 首页 / 详情页 - 节点展示

1. **简洁模式**：保持当前「距离 XX 天 还有 N 天」单行展示
2. **详细模式**：
   - 可增加「下一节点」小标签或图标，强化视觉
   - 可选：展示「最近 2 个节点」进度条（如 100 天 ✓、200 天 → 15 天）
3. **临近提醒**：当 `daysUntilNext <= remindDaysAhead` 且开启提醒时，可在卡片上显示小角标或提示「即将提醒」

### 4.3 节点列表展示优化

- 当前以 chip 形式展示，删除需点 X
- 可优化：
  - 长按显示「删除」或「编辑提前天数」（若采用方案 B）
  - 按数值排序展示（已支持），可增加分组：100～1000 / 1500+ 等
