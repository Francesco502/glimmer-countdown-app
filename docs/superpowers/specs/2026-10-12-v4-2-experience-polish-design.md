# 拾光 4.2 体验打磨设计

**状态：** 已实施，待发布（2026-10-12）。决策见“评审决定”，实施偏差与验证见“实施记录与偏差”和“本地验证记录”。

**目标：** 修复 4.1 遗留的界面缺陷，强化视觉层级，缩短常用操作路径，统一文案，并把 APK 从约 26MB 降到 10MB 以下；同时纳入自定义分类、事件配图、平板布局、动态取色与精确提醒（见单元 H）。

**来源：** 2026-10-12 对 v4.1 正式 APK 截图（`docs/screenshots/4.1/`）与源码（tag `v4.1` → `6c52a3a`）的审阅。下文中标注"待复现"的条目来自代码推断，实施前须先用失败测试或设备截图确认。

## 产品约束

- `versionName=4.2`、`versionCode=25`，沿用 v4.0/4.1 正式签名，唯一正式渠道仍为 GitHub Release 的 Direct APK `glimmer-countdown-4-2.apk`。
- Room 数据库从 version 10 升级到 11：新增 `categories` 表与 `events.imagePath` 列，迁移只做加法，保留全部既有数据。
- 保留宋韵视觉语言（纸笺、朱印、墨线、宋体），本版是"在风格内提高可读性与可用性"，不是改版。
- 所有行为修改遵循先写失败测试再修复；纯视觉修改以组件截图（ComponentUiEvidence）前后对照为证据。
- 发布门沿用 4.1：JVM、connected、lint、R8、正式签名、三平台 QA 与公开下载复验。

## 评审决定（2026-10-12）

1. 最近事件横幅默认开启，可在设置中关闭。
2. 分享卡、空状态等展示性位置完全保留宋韵措辞；白话化只作用于功能性按钮与提示。
3. 单事件小组件（F2）为 4.2 必须项。
4. 本版不安排实体手机验收，发布清单如实记录。
5. 自定义分类、事件配图、平板布局、动态取色、精确提醒纳入 4.2（单元 H）。
6. 允许子集字体改名（单元 B）。

## 非目标

- 云同步与新的备份文件格式（JSON 仅增加分类字段；配图不随 JSON 导出）。
- 重写导航架构（详情仍为状态驱动的覆盖层）。

## A. 缺陷修复（P0）

### A1 弹窗透底与分享预览裁切

**现状：** `SongDialogScaffold.kt:67` 以 `surface.copy(alpha = 0.98f)` 作为弹窗底色，叠加纸纹后底层内容可见（4.1 分享截图中可见"未开启事件提醒"残影）。分享预览卡片底边被弹窗内容区裁切。

**设计：** 弹窗表面使用不透明 `surface`，纸纹只作为不透明底色之上的纹理。分享预览区按 1080×1350 的 4:5 比例计算高度，在 `heightIn(max = maxHeight * 0.8f)` 约束下等比缩小，而不是裁切。

**验收：** 分享、删除确认、日期滚轮三个弹窗在浅色/深色下组件截图中无底层内容；预览卡片四边边框完整。

### A2 月历视图新建按钮遮挡

**现状：** 月历视图中居中的新建按钮压在"某日的事件"标题与列表之上（`HomeScreen.kt:2115` 底部留白 72dp），当日事件被挤出首屏。

**设计：** 月历视图的新建按钮改为右下角放置，并预填当前选中日期；当日事件列表底部留白统一取 `FabSize + 2 × PaddingBase`。六行月份在短屏下允许月历网格压缩行高（沿用 4.1 短高度策略），保证至少一条当日事件在首屏可见。

**验收：** 411dp×914dp、360dp×640dp 两种窗口下，选中有事件的日期后，第一条事件完整可见且不与按钮重叠。

### A3 小组件 2×2 预览行距

**现状：** `WidgetSettingsContent.kt:533` 在高度大于 1 格时使用 `Arrangement.SpaceBetween`，两行被推到上下两端。

**设计：** 预览行使用 `Arrangement.spacedBy(rowGap, Alignment.Top)`，与真实 RemoteViews 的自上而下排列一致；行数按高度格数推算（每格约 2 行），使预览反映实际可容纳条数。

**验收：** 预览与 Pixel Launcher 2×2 真实小组件截图行间距目测一致；新增 `WidgetPreviewPolicyTest` 断言行数推算。

### A4 版本号解析

**现状：** `GitHubReleaseUpdateChecker.kt:128` 使用 `String::toInt`，tag 含 `-beta`、`-rc1` 等后缀时抛异常，用户只看到笼统失败。

**设计：** 解析为"数字段 + 可选预发布后缀"，比较时数字段优先，带后缀版本低于同号正式版；无法解析时返回明确的"版本格式无法识别"结果而非异常。

**测试：** `4.2` > `4.2-rc1` > `4.1`；`v4.2`、`4.2.0` 与 `4.2` 相等；`abc` 返回格式错误结果。

### A5 深色模式小组件与自定义颜色

**现状：** `drawable-night/widget_background_translucent.xml` 在夜间仍为乳白玻璃 `#DDF2F3F0`，并强制深色字（`WidgetRenderPolicy.kt:203-205`）。应用内自定义颜色在浅色/深色共用一组值（`Theme.kt:118-131`）。应用内小组件预览的玻璃色忽略 `isDark`（`WidgetSettingsContent.kt:620-626`）。

**设计：**
- 墨线夜间改为深色玻璃（参考 `system_neutral1_900` 75% 不透明度），文字随之自动切换为浅色。
- 自定义颜色在 DataStore 中仍是同一组键；深色模式下对用户颜色做明度映射（保持色相，背景类降至 L≈12%，文字类升至 L≈90%），并继续经过 `ColorContrastGuardrail`。不新增独立的深色颜色设置，避免设置项膨胀。
- 预览使用与 RemoteViews 相同的颜色解析函数。

**验收：** 五种背景 × 浅/深 的组件矩阵截图，文字对比度均 ≥ 4.5:1（`ColorContrastGuardrailTest` 扩展）。

### A6 不透明度控件无效

**现状：** 不透明度只作用于"跟随系统"和"墨线"（`WidgetRenderPolicy.kt:89-147`），在宣纸/青瓷/朱印下选项可见但无效果。

**设计：** 对不支持透明度的背景隐藏该控件，并在背景选项下方以一行说明替代。不做"让所有背景支持透明度"，那需要新增大量 drawable。

## B. 包体瘦身（P0）

**现状：** `res/font/noto_serif_sc.ttf` 为 25,125,512 字节的完整可变字体，`zcool_xiaowei_regular.ttf` 为 6,313,808 字节，合计占 APK 26.4MB 的主要部分。

**设计：**
- 使用 `fonttools` 的 `pyftsubset` 生成子集：`通用规范汉字表` 一级 + 二级（6500 字）、GB2312 补集、ASCII、全角标点、农历与干支用字。
- Noto Serif SC 从可变字体实例化为 Light / Regular / Medium / SemiBold 四个静态字重（与 `Type.kt:15-18` 声明的四档一致），去除 `fvar`/`HVAR`/`gvar`。若四档静态子集合计超出预算，先评估 SemiBold 的两处用法能否改为 Medium。
- 子集脚本与字表提交到 `scripts/fonts/`，生成结果可重复（固定 fonttools 版本，记录 SHA-256），许可文件保持不变（OFL 允许子集化，但子集字体不得沿用保留字体名，须改名为 `Glimmer Serif`、`Glimmer Xiaowei` 等）。
- 缺字由 Android 文本渲染逐字回退到系统字体，不需要代码处理。

**目标：** 字体合计 ≤ 6MB，APK ≤ 10MB。

**测试：** 新增 JVM 测试读取字体 cmap，断言农历月名、干支、"正当此时""已经""还有"等界面用字全部覆盖；扫描 `values*/strings.xml` 中所有汉字，断言在子集内。组件截图对照 4.1，字形与字重无可见差异。

**风险：** OFL 的保留字体名条款需要逐个字体核对 `name` 表；如有疑问，退回到只做静态实例化（预计仍可降至约 12MB）。

## C. 首页与月历视觉层级（P1）

### C1 卡片信息层级

**现状：** 倒数数字为 `displaySmall`（28sp Light），标题 18sp，层级接近；今天显示"正当此时"无强调；已过去事件为"123 天"在上、"已经"在下，语序颠倒（`HomeScreen.kt:1488,1703`）；置顶事件无任何标记。

**设计：**
- 数字使用 `displayMedium`（约 40sp，Regular），单位"天"用 `labelLarge` 并底部对齐；24 小时内的小时显示同样处理。
- 前缀"还有 / 已经"置于数字之前同一行或上方小字，统一为"已经 123 天""还有 12 天"的阅读顺序。
- 今天：数字区替换为朱印样式的"今天"印章（朱红描边方印，字体沿用当前字体预设），卡片左侧色条加粗至 4dp。原"正当此时"保留为详情页大字。
- 置顶：卡片右上角 12dp 朱印小钉，列表行标题前同款图标；需要把 `pinned` 传入 `EventCard` 与 `EventListItem`。
- 数字区点击切换显示方式的行为保留，但首次使用时在数字下方显示一次"轻点切换天/周/月"提示（记录到 DataStore 一次性标记），并为该区域提供独立的无障碍操作名称。

### C2 最近事件横幅

在卡片视图列表顶部增加"最近"横幅：显示距今最近的一个未来事件（置顶优先）。横幅比普通卡片高约 1.5 倍，数字使用 `displayLarge`。搜索或筛选激活时隐藏；可在"显示与语言"中关闭（默认开启）。列表视图与月历视图不显示。

### C3 新建按钮

**现状：** 48dp 描边方块、无阴影、图标 70% 透明度（`HomeScreen.kt:262-289`），卡片列表底部留白只有 12dp（`:494`）。

**设计：** 56dp 实心朱红方块（`primary` 底、`onPrimary` 图标、4dp 圆角，延续印章意象），1dp 阴影。卡片与列表视图仍居中，月历视图右下（见 A2）。列表底部留白改为 `FabSize + 2 × PaddingBase`。首次空状态仍隐藏，由空状态主按钮承担。

### C4 常驻排序提示

`home_reorder_hint` 改为仅在首次切换到自定义排序时显示一次，并带"知道了"关闭；文案去掉对视障专用"上移/下移"操作的提及，改为"长按卡片拖动排序"。

### C5 月历格

**现状：** 今天默认即选中，今天的金边与圆点被选中的实心填充覆盖；格内无农历；事件仅为 4dp 方点；无滑动换月与回到今天。

**设计：**
- 选中：实心朱红。今天：朱红描边 1.5dp，选中今天时实心填充并在日期下方显示"今"字。
- 格内第二行显示农历日（初一显示月名，节气/传统节日优先，使用 `onSurfaceVariant` 小字）。英文界面不显示农历行。
- 事件点改为分类色圆点，最多 3 个，超过显示"+N"。
- `HorizontalPager` 实现左右滑动换月；标题右侧在非本月时出现"今天"文字按钮。
- 月历视图与卡片/列表视图一致地应用时间线筛选（现仅用 `calendarUiState`，`HomeScreen.kt:365`），或在筛选条中注明"月历不按时间段筛选"。推荐前者。

### C6 空状态

首页无事件时，在现有主按钮上方加一段两行说明（复用现有 `home_empty_title` 字符串）与一幅线描小图（使用 `SongLineIcons` 的风格绘制，Vector，不引入位图）。搜索无结果的空状态保持现状。

## D. 交互路径（P1）

### D1 搜索入口

顶栏在筛选图标左侧新增搜索图标，点击后顶栏原位展开为搜索框并自动聚焦弹出键盘；返回或清空即收起。筛选面板中的搜索框移除。搜索词与现有 `HomeViewModel` 搜索状态共用。

### D2 筛选激活状态

筛选图标只在"分类 ≠ 全部"或"时间段 ≠ 全部"时显示激活点；排序方式不属于筛选，不再点亮（修改 `HomeScreen.kt:733-736`）。

### D3 新建页焦点与顺序

- 新建时标题自动聚焦保留，但页面顺序调整为"标题 → 日期 → 分类 → 重复 → 提醒 → 备注"，使键盘弹起后日期仍在可视区。
- 预览卡片移到表单底部或改为可收起，避免被键盘遮挡后失去意义。
- 编辑已有事件时不自动聚焦。

### D4 快捷提醒

提醒开关打开后，直接显示一行快捷选项：当天 / 提前 1 天 / 3 天 / 7 天 / 自定义，以及时间（默认 09:00，点击打开现有滚轮）。权限说明弹窗仍在首次打开时出现。目标：从关闭到设置完成 ≤ 3 次点击。数据模型不变（仍为"提前 N 天 + 时间"）。

### D5 重复"自定义"选中态

`EventEntryScreen.kt:1066` 自定义重复芯片在自定义重复激活时 `selected=true`，并显示当前规则（如"每 2 周"）；文案改用独立字符串，不再复用 `category_custom`。

### D6 长按菜单

非自定义排序下，长按卡片弹出操作菜单：置顶/取消置顶、编辑、分享、删除。自定义排序下长按仍为拖动（行为不变）。删除依旧走现有确认与撤销。移除恒为 `false` 的 `homeCardLongPressEditEnabled` 等开关。

- 选项芯片改为换行排列，不再横向滚动隐藏。
- "已添加的小组件"去掉重复标题；实例名使用"2×2 · 首个事件名"而非 appWidgetId。
- "恢复默认"与"应用到已有小组件"执行后显示带"撤销"的提示条。

## F. 通知、小组件与更新（P1/P2）

### F1 提醒通知内容（P1）

**现状：** 标题固定"倒计时提醒"，正文 `"$title, $content"` 含半角逗号（`ReminderWorker.kt:63-64`、`MilestoneReminderWorker.kt:64-65`），无样式与操作；事件标题在调度时写入 work data，编辑后不更新。

**设计：**
- 标题为事件名，正文为"还有 3 天 · 10月15日（周四）"或"今天"；里程碑为"已经 1000 天"。
- `BigTextStyle` 显示备注首行；`setColor(primary)`；`CATEGORY_REMINDER`；同日多条使用分组摘要。
- 操作："查看"（打开详情）。
- Worker 执行时按 eventId 读取最新事件标题与日期，work data 中的标题仅作为读取失败时的回退。

**测试：** 扩展 `ReminderWorkerDeliveryPolicyTest`，断言文案构造、中英文标点、事件改名后通知使用新标题。

### F2 单事件小组件（P2）

新增第二个 `AppWidgetProvider`：单事件大数字样式（标题、大数字、单位、日期），1×1 到 4×2。配置页复用现有 `WidgetConfigActivity`，增加"选择事件 / 跟随最近事件"。不改动现有列表小组件的配置键。

### F3 小组件选择器（P1）

`xml-v31/countdown_widget_info.xml` 补充：`previewLayout`（指向使用示例数据的静态布局）、独立 `description` 字符串（"即将到来的日子列表"）、`minResizeWidth/Height`、`maxResizeWidth/Height`。`AndroidManifest.xml` 为配置 Activity 补 `APPWIDGET_CONFIGURE` intent-filter（实施前确认当前是否依赖其他方式启动）。

### F4 更新体验（P2）

- 下载显示进度条（已知 Content-Length 时为确定进度，否则不确定进度）。
- 安装前检查 `canRequestPackageInstalls()`，未授权时先引导到系统"安装未知应用"页面。
- "在浏览器中打开"改为打开 Release 页面而非 APK 资产 URL（`UpdateInstaller.kt:79-83`）。
- 更新说明做轻量 Markdown 处理（标题、列表、粗体），不引入依赖。
- 关于页补充源码、开源许可（OFL 字体许可）、反馈（GitHub Issues）链接，去掉重复标题。
- 不做后台自动检查（保持隐私与无网络请求的默认行为），在 4.3 评估是否加可选的每周检查。

## H. 扩展功能（P1）

### H1 自定义分类

- 新表 `categories(id TEXT PK, name TEXT, colorHex TEXT, sortOrder INTEGER, createdAt INTEGER)`。内置分类 `birthday`/`anniversary`/`other` 不入表，名称继续走字符串资源；自定义分类 id 为 `custom_<uuid>`。
- `events.category` 继续保存分类 id；删除自定义分类时，其事件改为 `other`（同一事务）。
- 设置新增“分类管理”：新增、改名、改色、排序、删除（删除前提示受影响事件数）。新建页分类芯片、首页筛选、详情标签、分享卡、小组件分类色统一读取分类仓库。
- JSON 导出新增 `categories` 数组；导入时按名称合并自定义分类，旧备份不含该字段仍可导入；导入校验接受备份内声明的自定义分类 id。

### H2 事件配图

- `events.imagePath TEXT NULL`，保存应用私有目录 `files/event_images/` 下的相对文件名。
- 新建/编辑页通过系统照片选择器（`PickVisualMedia`，无需存储权限）选图，按长边 1600px 压缩为 JPEG 后复制到私有目录；替换或删除事件时清理旧文件。
- 详情页头图与分享卡使用配图（加纸色蒙层保证文字对比度）；首页卡片右侧显示 48dp 缩略图。
- 配图不进入 JSON 导出，导出界面注明。

### H3 平板与横屏布局

- 依据窗口宽度分级（compact < 600dp ≤ medium < 840dp ≤ expanded）。
- expanded：首页左侧列表 + 右侧详情的双栏；medium：卡片视图两列网格。新建页与设置页内容最大宽度 640dp 居中。

### H4 动态取色

- Android 12+ 在“主题”中新增“跟随壁纸取色”开关（默认关）。开启后浅色与深色都使用动态配色，并保留宋韵纸纹、字体与圆角；自定义颜色在动态取色开启时不生效并给出说明。

### H5 精确提醒

- 新增“精确提醒”开关（默认关，仅 Direct 渠道）。开启且系统授予 `SCHEDULE_EXACT_ALARM` 时，用 `AlarmManager.setExactAndAllowWhileIdle` 调度；否则沿用 WorkManager。两条路径共享投递逻辑，取消与重排时同时清理两条路径，避免重复通知。Play 渠道移除该权限。

## 实施记录与偏差（2026-10-12）

实施中与上文不同、以本节为准的决定：

- **包体（B）**：静态四字重子集合计 17.5MB，超出预算。改为单个可变宋体子集（5.8MB，保留完整 GB2312 字集，避免人名常用字缺失）+ 站酷小薇一级常用字子集（2.0MB）；正式签名 APK 实测 12.5MB（4.1 为 26.4MB），目标由 ≤10MB 调整为 ≤13MB。
- **设置分组（E4）**：系统日历同步与里程碑/提醒共用状态较多，未拆成独立子页；入口更名为“提醒与日历”。“主题”入口更名为“主题与动效”，减弱动效与操作音效移入其中。新增“分类管理”入口。
- **小组件设置（E5）**：预览固定在编辑器顶部（不随页面吸顶）；“恢复默认”和“应用到已有小组件”改为执行前确认，而非事后撤销。
- **平板布局（H3）**：宽屏（≥840dp）为列表 + 详情双栏；中等宽度（600–840dp）沿用单栏并限制内容宽度，不做两列网格（自定义拖动排序依赖单列列表）。
- **单事件小组件（F2）**：背景、圆角、边框、文字对比沿用“默认配置”，实例只保存选中的事件（或跟随最近事件）。
- **事件配图（H2）**：删除事件不立即删除图片文件，以保证撤销后配图仍在；启动时清理一天前且未被引用的文件。
- **月历换月（C5）**：用水平拖动手势 + 切换动画实现左右滑动换月，未使用 HorizontalPager；月历事件计算本就只覆盖当月。
- **撤销删除（A7）**：核对后确认撤销以原 id 重新插入，置顶与自定义顺序保存在偏好中且删除时不清除，因此会一并恢复，无需改动。
- **搜索图标**：原装饰性搜索字形放到顶栏后难以辨认，改为线描放大镜。
- **自定义分类导出（H1）**：JSON 仍为事件数组，自定义分类以 categoryName / categoryColorHex 字段随事件导出，旧版本导入时这些事件会被计为无法解析。
