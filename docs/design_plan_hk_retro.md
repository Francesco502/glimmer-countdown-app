# Project TimeAPK: 港式复古（胶片风）UI 重构方案

## 1. 设计理念 (Design Philosophy)

**核心关键词**：**情绪 (Mood)**、**时间 (Time)**、**颗粒感 (Grain)**、**秩序 (Order)**

本方案致敬经典港式电影美学（如王家卫风格），将“倒计时”这一功能具象化为**时间的流逝与记录**。
- **Dark Mode (暗房/胶片)**：模拟冲印室的红光或夜晚的霓虹余晖。强调沉浸感、神秘感。
- **Light Mode (剧本/报纸)**：模拟泛黄的剧本纸张或旧报纸。强调书卷气、怀旧感。

---

## 2. 视觉规范 (Visual Identity)

### 2.1 色彩系统 (Color Palette) - V2 (航海/瓷砖风)

基于用户反馈优化，提升对比度与清晰度。从“墨绿胶片”转向“蓝白港式”配色。

#### **Dark Mode (维港夜雾 - Harbor Night)**
基于深蓝灰色系，营造夜晚海面雾气与暖色灯光的氛围。
*   **Background (画布)**: `#141622` (深海蓝黑) —— 沉稳的夜色背景。
*   **Surface (卡片)**: `#1E2230` (深蓝灰) 或直接透明 + `#3E4C6B` (午夜蓝) 描边。
*   **Primary (主强调)**: `#FDF4DE` (奶油杏色/暖光) —— 高对比度，模拟夜间灯光，用于倒计时数字，清晰醒目。
*   **Secondary (次要)**: `#3F6987` (钢蓝/铁锈蓝) —— 用于辅助信息、图标背景。
*   **Tertiary/Text**: `#BDB4BF` (紫灰/雾灰) —— 用于正文，柔和不刺眼，带有复古胶片的颗粒感。
*   **Accent (点缀)**: `#D65C5C` (复古砖红) —— 用于“过期”或紧急提示，保持复古印章感。

#### **Light Mode (蓝白瓷砖 - Ceramic Blue)**
基于蓝白清新色系，营造旧式茶室瓷砖或海报的清爽感，解决原方案过于暗淡的问题。
*   **Background (画布)**: `#FEFFFF` (冷瓷白) —— 清透的纸张或瓷砖质感。
*   **Surface (卡片)**: `#F5F9FC` (极浅蓝) 或 透明 + `#AFC8DA` (褪色丹宁) 描边。
*   **Primary (主强调)**: `#47709B` (复古海蓝) —— 用于标题、按钮和核心视觉元素，经典耐看。
*   **Secondary (次要)**: `#AFC8DA` (浅蓝灰) —— 用于分割线、次要标签、未选中状态。
*   **Accent (点缀)**: `#D65C5C` (砖红) —— 红蓝撞色是港式复古的经典标志。
*   **Text**: `#1A232C` (深蓝墨色) —— 替代纯黑，与蓝色背景更融合，阅读更舒适。

### 2.2 字体与排版 (Typography)

港式复古的灵魂在于中西混排的韵律感。

*   **标题 (Display)**:
    *   **中文**: **宋体 (Serif)**。Android 原生可尝试 `FontFamily.Serif`，如有条件引入 `Noto Serif SC` 效果更佳。字重偏细，字间距 (Tracking) 调大。
    *   **英文**: **衬线体 (Serif)** + **斜体 (Italic)**。模拟电影字幕。
*   **数字 (Numbers)**:
    *   **等宽字体 (Monospace)**。模拟打字机或机械翻页钟的效果。
*   **正文 (Body)**:
    *   清晰的无衬线体 (Sans Serif)，保证可读性，但字重不要太粗。

### 2.3 材质与纹理 (Texture)

*   **噪点 (Film Grain)**: 在全局背景上叠加一层极低透明度 (3%-5%) 的动态噪点，消除数字的“死板感”。
*   **暗角 (Vignette)**: 仅在 Dark Mode 下使用，屏幕四角略暗，聚焦中心内容。
*   **描边 (Stroke)**: 使用 **双线描边** 或 **粗细结合** 的线条，模拟旧式表格或票据。

## 3. 组件重构方案 (Component Redesign)

### 3.1 首页 (Home Screen)

*   **背景**:
    *   Dark: 深墨绿底 + 噪点。
    *   Light: 米黄纸底 + 纸张纹理（可选）。
*   **事件列表 (The Timeline)**:
    *   摒弃现在的“圆润气泡卡片”。
    *   **新造型**: **票据/胶片样式**。直角或微圆角 (4dp)。
    *   **左侧装饰**: 也就是现在的 color bar，改为类似 **“胶卷齿孔”** 的虚线，或者 **“折痕”** 的阴影效果。
    *   **状态表达**:
        *   *进行中*: 亮起的灯箱感（Dark） / 清晰的墨印（Light）。
        *   *已过期*: 压暗，甚至给文字加一条“删除线”，模拟被划掉的任务。
*   **FAB (悬浮按钮)**:
    *   改为 **正方形** 或 **菱形**。
    *   内部图标改为实心，类似一个“印章”。
*   **搜索栏**:
    *   只有底部一条线的 **Underline TextField**，像是在横格纸上写字。

### 3.2 详情页 (Detail Screen)

*   **大倒计时**:
    *   数字极大，使用 **Monospace** 字体。
    *   布局参考 **老黄历** 或 **电影场记板**。
    *   年月日显示为：“二零二六年 二月 六日”，尝试竖排或汉字数字（可选高级特性）。
*   **背景氛围**:
    *   可以使用模糊的事件相关图片作为底图，叠加深色蒙版。

### 3.3 设置页 (Settings Screen)

*   **列表**: 每一项之间用细实线分割 (`Divider`)。
*   **开关 (Switch)**: 样式复古化，方形滑块。

## 4. 技术实施路径 (Implementation Roadmap)

### Phase 1: 基础设施搭建 (Infrastructure)
1.  **定义 Color Palette**: 在 `Color.kt` 中定义 `RetroDark` 和 `RetroLight` 两套色值。
2.  **定义 Typography**: 在 `Type.kt` 中创建 `RetroTypography`，指定 Serif 和 Monospace 字体栈。
3.  **创建 Modifier 工具**: 编写 `Modifier.filmGrain()` 和 `Modifier.vignette()` 用于全局复用。

### Phase 2: 核心组件改造 (Core Components)
1.  **重写 `EventCard`**: 调整 Shape 为 `RoundedCornerShape(4.dp)`，调整 Border 和 Shadow，实现“票据感”。
2.  **改造 `HomeScreen`**: 替换背景，调整 FAB 样式，修改 TopBar 字体为 Serif。

### Phase 3: 细节打磨 (Polishing)
1.  **详情页重构**: 按照“场记板/老黄历”布局重写 `DetailScreen`。
2.  **动画**: 页面切换使用 **Fade Through** (淡入淡出) 而不是滑入滑出，模拟胶片切换。

## 5. 预期效果示例 (Conceptual Preview)

> **Dark Mode**
> 背景：深幽的墨色，四周微暗。
> 卡片：一张边缘泛着微弱金光的深色卡纸。
> 文字：宋体，“距离 纪念日 还有”，数字是发光的打印机字体 “10” 天。
> 氛围：安静，像在电影院等待开场。

> **Light Mode**
> 背景：温暖的米色纸张。
> 卡片：带有边框的票据，文字是清晰的油墨黑。
> 重点：红色的印章“紧急”。
> 氛围：怀旧，像翻看一本旧相册。
