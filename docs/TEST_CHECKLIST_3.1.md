## 一、首页

### 1.1 分类与筛选

- [ ] 顶部筛选芯片显示为「全部 / 生日 / 纪念日 / 其他」四类（无「即将到来」「已过期」）
- [ ] 点击「全部」显示所有事件
- [ ] 点击「生日」仅显示分类为生日的事件
- [ ] 点击「纪念日」仅显示分类为纪念日的事件
- [ ] 点击「其他」仅显示分类为其他的事件
- [ ] 切换分类后列表正确刷新，无错位或重复

### 1.2 排序

- [ ] 右上角有排序按钮（图标可见、可点击）
- [ ] 点击排序按钮弹出菜单：按剩余天数 / 按目标日期 / 按创建时间
- [ ] 选择「按剩余天数」后列表按剩余天数升序排列（即将到来的在前）
- [ ] 选择「按目标日期」后列表按目标日期升序排列
- [ ] 选择「按创建时间」后列表按创建时间排列，且支持自定义拖拽顺序（若已配置）
- [ ] 置顶事件始终排在最前，不受上述排序方式影响

### 1.3 卡片/列表展示与交互

- [ ] 卡片视图下：左侧为事件标题、日期，右侧为天数/年月日与状态标签
- [ ] 列表视图下：布局与卡片一致，列表项可点击进入详情
- [ ] 点击卡片/列表项**左侧区域**（标题、日期）→ 进入详情
- [ ] 点击卡片/列表项**右侧时间区域**→ 仅切换「xx 天」/「x年x月x天」显示，不进入详情
- [ ] 重复事件（纪念日/生日）在「还有xx天」时，标签为「距离 x 周年」「距离 x 岁」等具体文案（非笼统「还有」）
- [ ] 已过期事件显示「已经 x 天」或「已经 x 年 x 月 x 天」；未开始事件显示「还有 x 天」或「还有 x 年 x 月 x 天」
- [ ] 存在重大节点（如 100 天、1000 天）时，可切换到「里程碑」显示模式且文案正确
- [ ] **无左滑删除**：卡片/列表项左滑不会出现删除，删除仅通过详情页底部按钮操作

### 1.4 置顶

- [ ] 在详情页将某事件置顶后，返回首页该事件出现在列表最前
- [ ] 切换排序方式（剩余天数/目标日期/创建时间）后，置顶事件仍在最前
- [ ] 多个置顶事件时，按置顶顺序排列在列表顶部

### 1.5 导航与状态保持

- [ ] 从首页进入详情后，按返回键或界面返回 → 关闭详情，回到首页，列表滚动位置保持不变
- [ ] 旋转屏幕后若正在看详情，详情页保持显示不丢失
- [ ] 首页标题显示为「拾光」，字体随设置中字体预设变化（如有）

## 二、详情

### 2.1 基础信息展示

- [ ] 顶部显示事件标题，字号与样式正常
- [ ] 中部大数字为当前选中的显示模式（已历天数/已历年月日/剩余天数/剩余年月日/里程碑之一）
- [ ] 点击中部大数字区域可循环切换该事件的显示模式，与首页可选模式一致
- [ ] 重复类事件「剩余」模式下，副标题为「距离 x 周年」「距离 x 岁」等，与首页一致

### 2.2 纪念日「缘起｜已历｜静候」

- [ ] 分类为纪念日且为重复事件时，显示「缘起｜已历｜静候」三块
- [ ] 缘起：显示事件开始日期（公历 + 农历）
- [ ] 已历：显示已过去时长（文学化表述 + 天数）
- [ ] 静候：显示下次到来日期（公历 + 农历）
- [ ] 字号与对比度在浅色/深色主题下均清晰可读

### 2.3 生日信息（农历支持）

- [ ] 分类为生日时，可选择「公历 / 农历」两种日期类型
- [ ] 详情页中「农历」一行以「岁次 甲申 腊月 初八」等格式展示（包含干支与农历月日）
- [ ] 同时显示岁数、属相、八字、五行、星座等（若有），各标签与内容排版整齐，无遮挡或重叠

### 2.4 其他分类

- [ ] 分类为「其他」时，显示公历日期与农历（若有），农历同样采用「岁次 甲申 腊月 初八」等格式，无多余区块错位

### 2.5 备注与操作栏

- [ ] 有备注时在详情中部/中下显示备注内容，样式正常
- [ ] 底部操作栏包含：**置顶** / 编辑 / 分享 / 删除
- [ ] 点击「置顶」：按钮状态与文案变为「取消置顶」，该事件在首页置顶
- [ ] 再次点击「取消置顶」：恢复未置顶，首页顺序随排序规则变化
- [ ] 编辑：进入编辑页，数据回填正确
- [ ] 分享：弹出系统分享，文案包含事件标题与天数/状态
- [ ] 删除：弹出确认框，确认后删除并返回首页，列表更新

## 三、新建 / 编辑

### 3.1 基础字段

- [ ] 标题、日期、分类（生日/纪念日/其他）、重复类型、备注等字段均可正常填写与保存
- [ ] 编辑已有事件时，进入页面后各字段正确回填

### 3.2 日期选择器（3.1 重点：公历 / 农历双模）

- [ ] 点击日期字段弹出**底部弹窗**式日期选择器（非系统对话框）
- [ ] 弹窗内支持**年 / 月 / 日**三级滚轮选择，滚动结束后会自动吸附到中间高亮行
- [ ] 顶部有「公历 / 农历」分段按钮，默认跟随当前事件类型（新建默认为公历）
- [ ] 公历模式下：支持在输入框中**手动输入**年月日，与滚轮联动（修改输入后滚轮更新；滑动滚轮后输入框更新）
- [ ] 农历模式下：通过滚轮选择农历年/月/日（包含闰月），并以中文月份与日子展示，如「腊月」「初八」
- [ ] 输入非法日期时有校验或回退，不会写入无效日期
- [ ] 顶部有「确定」「取消」等操作按钮，确定后日期与是否为农历写入表单并关闭弹窗

### 3.3 分类与重复

- [ ] 分类切换为生日/纪念日/其他时，保存后首页与详情分类筛选与展示正确
- [ ] 重复类型：不重复 / 每年 / 每月 / 每半年 等可选，保存后首页与详情「已历/剩余」计算正确

### 3.4 颜色与提醒

- [ ] 可选取或输入自定义卡片颜色，保存后首页卡片颜色更新
- [ ] 提醒开关与提醒时间/提前天数设置可保存，且与通知行为一致（若已测通知）

### 3.5 保存与校验

- [ ] 必填项（如标题）为空时保存按钮不可用或给出提示
- [ ] 保存成功后返回上一页（首页或详情），列表/详情内容已更新
- [ ] 新建事件后，新事件出现在首页且排序/置顶逻辑正确

- [ ] 在 App 内添加/编辑/删除事件后，小组件在短时间内自动刷新（或按系统刷新策略）
