# 宋式美学 UI 深度优化实施方案

## 1. 目标与设计理念

基于“宋式美学”的极简、克制、留白与风雅，对当前应用的 UI、排版、色彩与文案进行一次深度的古典化重构。核心理念在于“做减法”：剥离大面积色块与现代工业组件感，引入真正的物理中文字体与传统排版韵律，使应用呈现出类似宋代书画与古籍折页的质感。

---

## 2. 具体优化方案

### 2.1 色彩与留白（克制与通透）

**目标**：消除厚重大色块，增加呼吸感。
*   **退底留白**：修改 `HomeScreen.kt` 中的 `EventCard`。废除大面积的半透明铺色（目前的 `juanbenTint`）。将卡片的 `containerColor` 统一改为主题的 `Surface` 色（宣纸/墨色）。
*   **点缀用色**：事件的专属颜色（`eventColor`）将仅被应用于：
    *   主倒计时数字的颜色（`daysDisplay`）。
    *   卡片的极细边框（宽度可调整为 0.5dp）。
    *   分类标签/印章的背景或文字色。
*   **增加边距**：扩大 `EventCard` 内部的 `padding`（如四周留出 24dp 甚至更多），并增加列表项之间的 `Arrangement.spacedBy` 间距，营造“疏可走马”的水墨留白感。

### 2.2 字体的物理落地（真正的神韵）

**目标**：解决 Android 默认 Serif 字体对中文支持不佳、缺乏古风韵味的问题。
*   **引入实体字体**：在 `app/src/main/res/font` 目录下引入开源的物理字体文件（建议为 `.ttf` 或 `.otf` 格式）。
    *   *推荐字体*：如无合适的开源瘦金体，优先使用**思源宋体 (Noto Serif SC)**，以呈现典雅的雕版印刷感。
*   **配置 Compose Typography**：在 `ui/theme/Type.kt` 中定义新的 `FontFamily`（如 `FontFamily(Font(R.font.noto_serif_sc_regular))`），并在 `typographyForFontPreset` 的预设分支（如 `preset = 4` 即瘦金体/宋体分支）中应用该物理字体，替换掉原有的模拟 `FontFamily.Serif`。

### 2.3 现代组件的古典化改造（剥离工业感）

**目标**：消除 Google Material Design 的工业风，改用古典意象组件。
*   **首页悬浮按钮 (FAB)**：
    *   取消默认的带有大色块的 `FloatingActionButton`。
    *   重构成底部居中的极简按钮：背景透明（或与背景同色），仅保留极细的圆圈边框和修长的「＋」号；或者用竖排文字（如“记事”）作为按钮。
*   **详情页底部操作区**：
    *   修改 `DetailScreen.kt` 中的 `DetailActionButtons`。
    *   废除 `OutlinedButton` 和 `Button` 的边框和背景填充。
    *   改为类似古画“题跋/落款”的排版：纯图标搭配极小的辅助文字（如“编辑”、“分享”），水平分散对齐，上方留出大量空白与主内容隔开。
*   **标签变“印章”**：
    *   在详情页或其他合适位置展示状态或分类时（如“生日”、“纪念日”），抛弃圆角背景色块。
    *   封装一个新的 `SealTag` 组件：正方形或长方形比例，使用朱红色或事件专属色作为底色（阳文）或边框（阴文），内部配以宋体或篆体文字，模拟中国传统印章。

### 2.4 文案的深度古典化（语境统一）

**目标**：统一全应用文案的古典意境。
在 `res/values/strings.xml`（及多语言版本）中进行以下替换：
*   **启动页**：“在时间的深海里，拾起一缕微光” ➡️ **“白驹过隙，拾光留痕”**。
*   **首页空状态**：“还没有任何倒计时” / “点击下方 + 添加第一个” ➡️ **“空空如也，待录佳期”**。
*   **今日标签**：“就是今天” ➡️ **“正当此时”**。

### 2.5 详情排版的韵律感（对齐与线条）

**目标**：打破单调的居中对齐，引入古典书籍的排版美学。
*   **古典分隔符**：在 `DetailScreen.kt` 的主时间数字下方，绘制一条**细长且两端渐隐的水平线**（可通过 Canvas 绘制带有透明度渐变的直线）。
*   **折页式区块排版**：
    *   改造“缘起｜已历｜静候”六行区块以及生日详情区块。
    *   整体左侧增加较大的缩进（padding），使文本整体偏右或呈现错落感。
    *   在左侧 Label（如“缘起”）和右侧 Value 之间拉开明显层次。
    *   可选：在区块最左侧绘制一条贯穿前后的极细直线（透明度 10%-20%），模拟古籍的“装订线”或“折页线”。

## 4. 验收标准
1.  **视觉通透**：首页不再有大片高亮色块，界面呈现宣纸般的干净质感。
2.  **字体生效**：中文字体明显转变为宋体/雕版质感，不再回退到系统黑体。
3.  **组件无违和**：FAB 与底部按钮不再有工业化的填充框，融入留白。
4.  **文案契合**：启动页、空状态、今日标签意境统一，无白话违和感。
5.  **排版风雅**：详情页出现渐隐分隔线与错落有致的“折页”文字排列。
