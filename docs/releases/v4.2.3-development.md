## 问题与原因

反馈：覆盖升级 4.2.2 后，应用内事件正常，桌面旧小组件无内容；删除后无法完成新增小组件。

用户补充：设备为 vivo X Fold3 Pro，Android 16 / OriginOS 6；新增时可以进入配置页，但点击保存无反应，并非系统小组件列表中找不到应用。该表现与下面的刷新等待路径吻合；用户随后确认修复包覆盖安装测试通过，小组件显示和新增保存均正常。

代码中确认存在循环等待：

1. `CountdownAppWidgetProvider` 在 `WidgetRefreshCoordinator` 的互斥锁内调用 `updateAppWidget` 和 `notifyAppWidgetViewDataChanged`。
2. 启用旧列表适配器转换的 Android 系统会同步等待 `RemoteViewsFactory.onDataSetChanged` 返回。
3. `CountdownRemoteViewsFactory` 加载数据时又等待同一把锁，发布与数据回调因此互相等待。
4. 配置页保存会等待刷新完成，因而这个问题也会阻止新增小组件完成。

Android 同步转换路径参见 [AOSP AppWidgetManager.tryAdapterConversion](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/core/java/android/appwidget/AppWidgetManager.java)（本次检查的 blob 为 `67ad4594599fe59583ac6f1652fb2ab8271456e1`）。这是代码层面确认的故障路径；已取得反馈手机型号、系统版本和具体症状，用户已确认修复后的显示和新增保存正常，尚未取得设备日志。
