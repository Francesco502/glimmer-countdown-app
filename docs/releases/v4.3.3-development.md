# 4.3.3 验证记录

4.3.3（versionCode 33）更新拾光的桌面图标、启动画面和单色图标。浅色采用偏白宣纸底、深墨和汝窑青，深色采用深底、浅墨和汝窑青。两种模式共用同一矢量轮廓。

- [深色矢量](../brand/glimmer-logo-dark.svg)

正式 APK 覆盖升级基线为公开的 4.3.2（versionCode 32）。测试结果和发布资产以执行记录为准。

- 本机 Android 16（API 36）使用独立模拟器运行正式签名包，覆盖升级保留事件数据，草稿恢复、六个页面和分享回归通过。两种冷启动截图均检出对应的背景、墨色和汝窑青。
- 首轮桌面入口是 Pixel 的推荐图标。将拾光手动固定到桌面后，以同一快捷方式复测。关闭系统「主题图标」时，系统切到深色并等待 30 秒，图标仍保留浅色配色。在模拟器上改变应用组件状态以触发刷新后，原位置的图标显示深色配色，随后切回浅色又保留深色配色。组件状态与系统设置在测试后已恢复。
- 开启系统「主题图标」后，同一快捷方式按浅色、深色、浅色、深色顺序切换，四次均显示对应的系统着色，保留拾光轮廓。该选项使用系统颜色，并依赖桌面对主题图标的支持。

- 正式签名包在 API 26、31、36 均通过覆盖升级和进程终止后的草稿恢复。API 36 的页面与分享回归通过。[正式包 QA](https://github.com/Francesco502/glimmer-countdown-app/actions/runs/44765831150)
