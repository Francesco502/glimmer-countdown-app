## 代码检查结论

4.2.3 的半透明背景通过多层 drawable 叠加实现，25 / 50 / 75 档的基础填充已约为 70 / 78 / 87% 不透明，再叠加高光，实际差异很小。半透明样式的 0 和 100 还会回退到中间档。此前只验证资源互不相同，未验证最终像素 alpha。

本版把背景填充改为不带透明度的单层资源，在独立 ImageView 上统一应用百分比；保持文字和内容不透明。列表、单事件、预览共用同一处理，刷新会同时清理旧背景层。低不透明度下为列表文字使用阴影保护。边框和圆角继续使用原有设置。

滑杆范围为 0–100，无固定档位，按 1% 保存，松手后更新。配置继续使用现有整数字段与 JSON 格式，原有 0 / 25 / 50 / 75 / 100 值可继续读取；非法值限制到范围内。新建及缺省文字颜色原本已为自动，本版明确显示为“自适应”，保留用户手动选择。复查另发现朱印样式无条件强制浅色文字，现已修复为尊重手动深色文字。

自适应根据系统深浅色主题工作，不读取桌面壁纸的局部像素。背景只有透明叠加，没有增加实时模糊能力。100% 保留原有不透明主题表面，因此与 99% 的玻璃色调可能略有不同。
