# 拾光 Glimmer 4.2.2

发布说明；当前处于正式发布流程，公开状态以 GitHub Release 和验证记录为准。

本次更新重点修复生日小组件，让桌面上的生日默认显示距离下一次生日的天数，并改善小尺寸、大字号和语言切换时的显示体验。

## 小组件

- 每年重复的生日默认显示下次生日倒计时，生日当天显示“今天生日”。升级后已有列表小组件采用此规则，应用内原有显示选择保留。
- 每个列表小组件可独立选择“自动”“跟随应用”或“倒计时”；“跟随应用”同步事件详情页保存的显示方式。
- 首页、详情页保存显示方式后主动刷新小组件。
- 按实际宽度及字号选择文案；空间不足时上下排布，保留时间方向、单位及完整无障碍描述。
- 预览使用真实事件和桌面布局，统一采用应用语言；切换语言、系统字号后刷新。
- 单事件小组件配置增加加载保护、保存防重入及失败重试。

## 事件配图

- 修复正常图片在导入尺寸探测时被误判为读取失败的问题。
- 系统备份与换机迁移纳入事件配图；JSON 导出仍不包含图片。
- 无引用图片采用保守的延迟清理，保护未完成草稿及撤销删除。

## 升级说明

- 版本：4.2.2，versionCode 27；Android 8.0（API 26）及以上。
- 已结束的单次事件不会被改为每年重复；公历、农历及重复日期规则沿用原有算法。
- 正式下载资产计划为 Direct APK `glimmer-countdown-4-2-2.apk`，沿用原正式签名以支持覆盖安装。

验证记录见 [开发记录](v4.2.2-development.md)、[结构化证据](v4.2.2-verification.json)和[升级验收清单](v4.2.2-upgrade-acceptance.md)。真实 Launcher 旧绑定迁移、完整桌面日期/时区矩阵、系统图片备份恢复及实体手机检查仍未执行；自动组件测试和普通事件升级不替代这些验收。
