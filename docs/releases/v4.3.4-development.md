## 实现范围

- 首页卡片与账页统一倒数排版，账页采用本次发生日的星期。分类与双历日期参与搜索，长按可打开事件菜单或拖拽重排，月历「今」使用固定槽位。
- Direct 在首帧后静默检查更新。自动检查间隔为 24 小时，「稍后」静默 72 小时，「忽略此版」按版本记忆。已选更新共用下载与安装流程。Play 由应用商店管理更新。
- 分享笺提供宣纸、玄墨、汝窑青三套配色以及可切换的农历和备注。单事件桌面小组件支持实时预览、搜索和每实例外观。桌面快捷菜单含两个静态入口及前两个有效置顶事件。
- Room 升至 13。往事匣收纳已结束的单次事件，归档时取消应用内提醒并清理受管系统日程。旧提醒由提前 `N` 天与当天触发，`N=0` 时仅当天。农历每月重复包含闰月，三十在小月按廿九处理。
- ZIP 备份包含配图、分类、置顶、排序和自定义节点。导入并入现有记录，并按导入后的事件 ID 恢复顺序。继续支持 JSON 和 `.mdb` 导入。
